# Reference scenarios

102 scenarios with expected answers, generated by `build_scenarios.py`. The machine-readable form is `scenarios.json`; this file is the same content for reading.

Expected answers for `ok` and `infeasible` come from a brute-force search over every subset of the active cards. Expected `invalid` answers are single mutations of a valid request, labelled by hand against the contract. If the solver disagrees with a scenario, check the contract before changing either side.
